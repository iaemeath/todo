# 产品能力清单

> **现在时**文档：随功能上线同步更新（新能力入节，废弃能力标注）。本文只盘点"有什么"，
> 架构如何实现见各域文档（如 [sync/](sync/current.md)）。
> 最后校准：2026-08-28（v0.3.0 + 同步实时化三连改之后）。
> 规模：前端约 1.0 万行 TS/Vue + 服务端约 1.5 千行 TS + 双端测试约 900 行。

## 端形态

一份 Vue 3 代码三端交付：**Web**（nginx 静态 + 同源 /api）、**Electron 桌面**（本地壳 + 远程 API，
托盘常驻/自动更新）、**Capacitor Android**（原生壳 + 系统闹钟/沉浸全屏）。三端更新通道独立：
Web 运行时 version.json 比对提示刷新、桌面 electron-updater 全自动（generic feed + 6h 轮询）、
Android APK 手动分发。

## 任务域

- 任务树：父子层级（最多 3 级）、孤儿自动提升顶级、父链完整性过滤
- **四象限法则**：重要 × 紧急双轴（艾森豪威尔矩阵），矩阵视图即顺序唯一编辑入口（象限内拖拽重编号）
- 树/矩阵双视图；未完成/已完成切换且**视图状态持久化**
- 完成态联动：完成下推子孙、取消上推祖先（父完成只由手动勾选决定）
- Fuse.js 模糊搜索（标题 + 描述，threshold 0.4）
- 待办栏（TodoSidebar）：只列叶子任务，按象限主序 + 组内序

## 日程域

- FullCalendar 日/周/月视图；中央时间选择器导航
- 拖拽调度：eventDrop / eventResize / eventReceive 三处跨零点校验（endTime ≤ startTime 拒绝并回滚）
- 共享 ScheduleDialog（CalendarArea / TaskManagePage 双入口）
- 状态二段切换（未进行/已进行，按结束时刻划分）；搜索与状态/颜色筛选相交过滤
- 日程可关联叶子任务（addScheduleFromTask，墓碑任务拒绝排期）

## 同步域（详见 docs/sync/）

- **local-first 记录级同步 v4.5**：LWW 双时间戳（rev 裁决 / recv_time 游标）、墓碑传播、
  settings 字段级记录化、usage 追加流水幂等合并
- **SSE 实时信令**：对端推送秒级唤醒（一次性票据认证、tag 排除自身、自管退避重连）
- 推送调度：前沿立即（距上次推送 >30s）/ 后沿 2s 节流微批；兜底轮询 5min（SSE 健在降频 30min）
- 触发链：变更推送 / 页面隐藏 keepalive 补推（≤60KB）/ 手动 syncNow / 被拒即拉
- pull 复合游标分页（500/页，整轮应用幂等）；服务端逐条限流（push 30/分、pull 60/分）

## 提醒域

- 全局日程提醒：15s 到点窗口、**错过静默跳过不补发**（用户裁决：过期提醒是噪音）
- 三通道分发：Web Notification / Electron 托盘系统通知+图标闪烁 / **Android AlarmManager**
  （差集同步，应用被杀/重启照发）
- 屏保全屏 Wake Lock（防息屏，退屏释放/切后台回收三路降级）

## 认证与账号

- 邮箱注册（可选邀请码）+ 登录 + 忘记密码 + 自助改密（改密重签 token、其他设备强制下线）
- 验证码邮件（SMTP）；注册/忘记密码过滑块人机验证（自绘滑块，服务端手写 PNG 编码）
- 安全：scrypt 密码哈希、手写 JWT + token_ver 会话吊销、登录双维度限流
  （同邮箱 5 次/同 IP 20 次锁 10 分钟）、弱口令校验前后端共享纯函数

## AI 与语音

- **语音助手**：浏览器内 WebLLM 推理（本地模型缓存管理，零云依赖可用）或云端 API 双模式
- 自然语言意图解析 → 建任务/建日程（处理器表分发，默认值单一数据源）
- AI 用量流水记录（usage 同步）

## 屏保与桌面体验

- Fliqo 风翻页时钟屏保：4 卡分钟翻页、墙钟对齐 tick 防漂移、切后台自校准、12/24 小时制
- 屏保双配色（黑底白字/白底黑字）：默认跟随全局明暗主题，工具条按钮手动切换并记忆
- 屏保 3 小时时间带：now 恒在中线，任务卡融入带中（块=任务卡：日程色按经过进度染色、上标题/下描述），按起止定位错行，整点刻度轴；可见行数移动端 2 行 / Web 3 行，超出滚动半行
- 日程描述字段：排期继承任务描述、日程弹窗可编辑，日历事件悬浮可见
- 全屏沉浸（Android 壳内 SystemBars 全屏 + 横屏锁 + edge-to-edge + 安全区适配）
- 屏保工具条 3s 闲置淡出、指针活动唤出
- Electron：托盘常驻、关窗驻留（可配直退）、单实例、开机自启

## 数据管理

- 导出/导入备份文件（ExportBundle 契约校验 + 逐条净化）；apiKey 随备份携带
- 云端恢复（整体覆盖，警示先行）；同步状态指示器 + 手动立即同步
- 壳内服务器地址编辑器（支持 https，明文 http 警示）

## 服务端（Express 5 + node:sqlite，Node ≥ 22）

- 零 npm 运行时依赖哲学（JWT/滑块验证码/PNG 编码全手写）；监听 127.0.0.1:8787 由 nginx 反代
- 用户管理后台（管理员白名单）：列表/改密/删除
- SSE 事件通道（一次性票据、每用户 8 连接上限、25s 心跳）

## 质量基建

- 前端 21 例单测（node:test + tsx 零新依赖）：同步裁决语义全链路 + 推送调度 + 任务树删除
- 服务端 24 例单测：契约/弱口令/JWT/滑块
- vue-tsc 全项目类型检查（含测试项目）；stylelint 设计令牌强制（禁裸值）
