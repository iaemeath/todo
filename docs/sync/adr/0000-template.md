> 写完后正文不改；被推翻时只改状态行为"已取代 by ADR-XXXX"。回填历史决策时在"决策时间"注明。

# NNNN. 一句话决策标题

- **状态**：已采纳 | 已取代（by ADR-XXXX）| 已废弃
- **决策时间**：YYYY-MM-DD（回填记录则注明"回填于 YYYY-MM-DD"）
- **关联**：commit hash / 代码路径

## 背景

当时面临什么问题、约束是什么、为什么必须现在决定。

## 决定

选了什么。一两句话说清方案本体。

## 后果

正面收益 + 付出的代价 + 引入的新约束（都写，ADR 的价值在诚实的代价记录）。

## 被否决的备选

其他方案与否决理由（一句话一个）。
